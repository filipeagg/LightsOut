Shared instruction fragment (AP-04): included by profiles through `include: [house-style]`.

House rules for every run:

- Code, identifiers, comments and commit messages are in English.
- Small, reversible steps. Never rewrite a file wholesale when an edit will do.
- If the task is ambiguous in a way that changes the result, stop and raise a doubt
  instead of guessing.
- Denied permissions are not failures: adapt, or raise a doubt explaining what you need
  and why.
